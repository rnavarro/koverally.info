Website is built using [Hugo](https://gohugo.io/)

If you just want to update a single page, you do not need to clone the whole repo, just edit the page within Github and create the pull request.  One of us will merge it if applicable.

If you would like to propose a new layout using Hugo, please submit a pull request so it can be tested.

Once a pull request is merged, the build is automated through Cloudflare pages and will be live almost instantly.

If you are interested in taking over the entire project and domain name, please reach out to me.  I would like to see it flourish and thrive, as I don't have much time to work on it.
